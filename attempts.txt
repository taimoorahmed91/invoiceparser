ATTEMPT 6: pdfjs-dist with GlobalWorkerOptions.workerSrc = false
-----------------------------------------------------------------
Commit: f8be4f2 - Disable pdfjs worker by setting workerSrc to false
Status: FAILED - Runtime Error

Error:
  Setting up fake worker failed: "Cannot find module './pdf.worker.js'"

Issue:
  - Setting workerSrc to false still tries to initialize worker
  - pdfjs-dist fundamentally requires worker for text extraction
  - Worker file not bundled in Vercel serverless deployment
  - Cannot use pdfjs-dist in serverless without worker file

Code attempted:
  const pdfjsLib = await import('pdfjs-dist/legacy/build/pdf.js');
  pdfjsLib.GlobalWorkerOptions.workerSrc = false as any;
  const loadingTask = pdfjsLib.getDocument({
    data: uint8Array,
    useWorkerFetch: false,
    isEvalSupported: false,
    useSystemFonts: true,
  });

Conclusion:
  - pdfjs-dist is NOT suitable for serverless environments
  - Requires worker thread which cannot be bundled properly
  - Need a different library designed for Node.js/serverless

LESSONS LEARNED:
===============

1. pdf-parse v2.x is NOT serverless-compatible (requires browser APIs)
2. pdf-parse v1.x is serverless-compatible but loses layout structure
3. pdfjs-dist needs explicit worker disabling for serverless
4. Layout preservation is critical for invoice parsing (need X/Y coordinates)
5. GlobalWorkerOptions.workerSrc = '' alone is insufficient

NEXT STEPS IF ATTEMPT 5 FAILS:
==============================

Option A: Use pdf-lib instead (lower-level PDF manipulation)
Option B: Pre-process PDFs to extract text on client-side before upload
Option C: Use external PDF parsing service (AWS Textract, Google Document AI)
Option D: Copy pdf.worker.js into public folder and reference it
Option E: Use pdf.js in "no worker" mode with proper configuration
