========================================================================
KEY LESSONS LEARNED
========================================================================

1. Library Compatibility
   ❌ pdf-parse v2.x → NOT serverless-compatible (browser APIs)
   ⚠️  pdf-parse v1.x → Serverless-compatible but loses structure
   ❌ pdfjs-dist → Requires worker threads, not serverless-friendly
   ✅ unpdf → Designed for serverless, perfect fit

2. Worker Threads
   - Cannot be disabled in pdfjs-dist for text extraction
   - Not bundled properly by Vercel/webpack
   - unpdf handles this internally

3. Type Handling
   - Web APIs use ArrayBuffer → Uint8Array
   - Node.js prefers Buffer
   - unpdf specifically requires Uint8Array

4. Layout Preservation
   - Critical for itemized invoice parsing
   - pdf-parse v1.x loses this
   - unpdf preserves enough structure

5. Serverless Constraints
   - No browser APIs (DOMMatrix, canvas)
   - No external worker files
   - Limited bundle size
   - Must be purely Node.js compatible
